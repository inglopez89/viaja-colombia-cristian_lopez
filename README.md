# Viaja Colombia

Sitio web estático de turismo para descubrir destinos, gastronomía, festividades y guías de viaje en Colombia. Está desarrollado con HTML y CSS, sin dependencias ni frameworks externos.

## Descripción

Este proyecto presenta una experiencia de navegación sencilla para explorar información relevante sobre:

- Lugares turísticos
- Gastronomía típica
- Festividades y celebraciones
- Guías de viaje
- Información sobre la empresa/proyecto

La estructura del sitio está pensada como un landing page con varias secciones temáticas accesibles desde el menú principal.

## Tecnologías utilizadas

- HTML5
- CSS3
- Imágenes locales
- Videos embebidos de YouTube

## Cómo ejecutar el proyecto

Como es un sitio estático, no necesitas instalar dependencias.

### Opción 1: Abrir directamente
Puedes abrir el archivo `index.html` directamente en tu navegador.

### Opción 2: Servidor local
Desde la raíz del proyecto ejecuta:

```bash
python3 -m http.server 8000
```

Luego abre en tu navegador:

```text
http://localhost:8000
```
